# evals: регрессионные кейсы

Набор эталонных текстов с ожидаемой оценкой, чтобы ловить регрессии при изменении ядра или скиллов.

## Зачем

`writing-rules.md` и скиллы растут добавлением правил. Новое правило может незаметно сломать поведение на старых текстах: занизить живой текст, пропустить машинный, начать штрафовать за нормальную деловую сухость. Эти кейсы, страховка: прогоняешь их после каждого изменения ядра и сверяешь, что балл и находки не поехали.

## Формат кейса

Один файл на кейс в `cases/`. Внутри:

- **Текст.** Что подаём на вход.
- **Тип.** Пост / статья / README / доки.
- **Ожидаемый балл.** Диапазон (например, 2–3 или 8–9), не одно число: аудит субъективен на ±1.
- **Что аудит обязан поймать.** Ключевые паттерны. Не поймал, регресс.
- **Чего быть не должно.** Ложные срабатывания (штраф за цитату, за деловую сухость, переписывание вместо разбора).

## Как прогонять

Ручной прогон в Claude Code:

1. Дай команду вида «проверь этот текст» и вставь **Текст** из кейса.
2. Сверь балл с **Ожидаемым**, а список паттернов с «Что аудит обязан поймать».
3. Балл вне диапазона или пропущен ключевой паттерн, разберись, что из недавних правок это сдвинуло.

Полуавтоматически: те же кейсы можно гонять через API батчем и сравнивать балл. Но глазами всё равно смотри на список находок, одна цифра мало что говорит.

## Измеримость (когда кейсов станет больше)

Чтобы прогон был не «на глаз», а с числом:

- **Человеческий эталон (ground truth).** У каждого кейса ожидаемый балл-диапазон и список паттернов, которые аудит ОБЯЗАН найти. Это и есть правда, с которой сверяемся.
- **Медиана из 3 прогонов.** Балл аудита сам по себе шумный (судья не идеально самосогласован). Гоняй кейс трижды и бери медиану, а не один прогон.
- **Согласие числом.** Меряй, насколько аудит совпадает с эталоном: κ (каппа Коэна) по попаданию балла в диапазон, TPR/TNR по «поймал ли обязательные паттерны». Падает κ, правки сдвинули поведение.
- **Якоря.** Пару размеченных кейсов держи как few-shot-образцы для самого аудита (на них ссылается `audit.md`: 01 ≈ 2–3, 02 ≈ 8–9, 03 ≈ 4–5).

## Осторожно

Кейсы стареют вместе со стоп-листами (см. заметку про дрейф словаря в `writing-rules.md`). Раз в несколько месяцев перечитывай: не устарел ли эталон, не изменилось ли поведение модели.
