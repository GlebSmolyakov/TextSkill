# Ответы агента в чате: слепое сравнение

Проверяет, лучше ли агент отвечает по карточкам `chat-style.md`, чем по прежнему набору запретов.

1. На каждый сценарий из `scenarios.md` генерируются два ответа в чистом контексте: с прежними инструкциями и с карточками. Генератор видит только «Контекст» и «Сообщение».
2. Ответы перемешиваются под метками 1 и 2, ключ хранится отдельно.
3. Автор выбирает лучший в каждой паре, не зная, где какой вариант. Отдельно отмечает, где ответ потерял обязательный ход из «Обязан».
4. Вторичная метрика: число находок `scripts/lint_text.py` по каждому ответу.
