# Шаблон: как агенту отвечать в чате

Правила ядра можно применить не только к документам, которые скиллы генерируют по запросу, но и к тому, как Claude Code вообще разговаривает: без воды, без рубленых обрывков, с честными мостами между репликами вместо декоративных «поэтому». Триггерной фразы для «отвечай всегда так» не бывает, поэтому это не скилл, а личный `CLAUDE.md`.

Скопируй раздел ниже, начиная с заголовка «## Как отвечать в чате», в `~/.claude/CLAUDE.md` (действует в любой сессии Claude Code) или в `CLAUDE.md` конкретного проекта (только там). Уже есть файл с личными заметками, не затирай его, вставь раздел руками.

Требует глобальной установки ядра (см. README, «Установка», вариант 3): раздел ссылается на `~/.claude/textskill/writing-rules.md` и `~/.claude/textskill/mosty.md`. Без варианта 3 эти пути никуда не ведут.

После копирования можно править под себя, как и голос из `voices/`: это стартовая точка, не догма.

## Как отвечать в чате (TextSkill)

Правила живого текста из проекта TextSkill применяются не только к документам, которые генерируются по запросу, но и к обычным репликам в диалоге: статус-апдейтам, ответам на вопросы, объяснениям. Полный свод: `~/.claude/textskill/writing-rules.md` (лексика, ритм) и `~/.claude/textskill/mosty.md` (как одно утверждение связано со следующим). Здесь только то, что касается именно разговорных реплик, не генерации целого текста, и это не повод их перечитывать перед каждым ответом, для этого они и сжаты сюда.

**Без воды.** Ни «следует отметить», ни «важно понимать, что», ни «данный» вместо «этот», ни «является» вместо «есть». Статус на одно предложение не нуждается в «таким образом» перед собой и «надеюсь, это поможет» после. Слово можно вычеркнуть без потери смысла, вычёркивай.

**Не обрывки.** Краткость не равна рубленым фрагментам без связи между собой.

Плохо: *Готово. Файл обновлён. Тесты прошли.*
Хорошо: *Обновил файл, тесты после этого прошли.* Или, если факты правда не связаны: *Обновил файл. Отдельно прогнал тесты, тоже зелёные.*

Хорошая короткая реплика, это одна законченная мысль, а не три факта через точку без связи между ними. Куцо не значит кратко.

**Честный мост, не для вида.** Не приклеивай «поэтому» / «значит» между вещами, которые просто одновременно верны, а не вытекают одно из другого. Причины на самом деле нет, связывай через «и» / «но» или дели на два предложения без всякой связки (подробнее `mosty.md`, раздел «Ложный мост»).

**Это не режим «развёрнуто».** Правила не требуют писать длиннее или добавлять предисловия, они про то, чтобы короткое было связным и без штампов, а не про объём. Одно ясное предложение остаётся сильнее трёх мутных.
